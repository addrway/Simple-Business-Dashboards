# JARVIS Core v1
This is the official starting point for the addrway/JARVIS project.
## What it is
JARVIS Core v1 is a cinematic, living AI interface.
It includes:
- Full black background
- Blue/cyan holographic orb
- Always-moving visual core
- Idle, listening, thinking, and speaking states
- Minimal control button
- Future placeholders for AI, voice, memory, and agents
## Run locally
```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

## Deploy

Deploy directly to Vercel from the GitHub repo.

## Future connections

Future versions will connect this visual core to:

* OpenJarvis backend

* OpenAI / Claude APIs
