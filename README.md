# SBD — Simple Business Dashboard

Phase 1 SaaS dashboard for small businesses. Built with Next.js App Router, TypeScript, Supabase, Recharts, and TanStack Table.

## Setup

1. Add the environment variables from `.env.example` to Vercel.
2. Run `supabase/schema.sql` in the Supabase SQL editor.
3. Deploy on Vercel.
